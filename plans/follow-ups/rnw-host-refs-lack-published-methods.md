- **Terms:**
  - **Seam:** a module pair in `src/primitives`, a native file and a `.web` file, through which the components of Firna reach the platform packages.
  - **RNW route:** an app that draws its own screens with `react-native-web` (RNW) applies `resolveFirnaRnwFile` of `@firna/ui/rnw`, and Firna then draws with RNW too.
  - **DOM backend:** Firna's own web renderer under `src/primitives/dom`, which every web app uses when it does not take the RNW route.
  - **RNW form:** the file that the RNW route loads for a seam, which `src/primitives/rnwForms.ts` names as `native` or `web`.
  - **Public ref:** a ref prop of a public component, such as `Button.buttonRef`, that receives the host element that the component mounts.
