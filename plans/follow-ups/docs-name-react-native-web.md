- **Terms:**
  - **`react-native-web` (RNW):** the npm package that renders React Native components in a browser. The library rendered web through it until pull request #168. Today it does so only on the RNW route.
  - **DOM backend:** the library's own web renderer under `src/primitives/dom`. It renders plain React DOM elements, and it is the default web renderer. The protocol docs call it "the library's own DOM backend". Older docs call it "the web backend".
  - **RNW route:** an app that draws its own screens with RNW applies the rule of `@firna/ui/rnw`, and the library then draws with RNW too.
  - **Opening line:** the sentence at the top of a component `README.md` that names the platforms of the component. It is the first sentence, except in `src/video-editor/README.md`, where it is the second.
  - **Mechanics note:** a sentence in a `README.md` that explains how a web behaviour works inside the library.
